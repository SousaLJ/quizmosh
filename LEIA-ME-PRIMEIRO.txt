LUDRIVO — A TURMA FAZ O JOGO. — BETA 0.5.0

Jogo para PC pelo navegador. Interface em português e inglês, 92 perguntas, quatro modos,
salas multiplayer, treino com bots e tela coletiva.

IDIOMAS E CULTURA
O idioma do navegador sugere a interface, e você pode alterá-lo no cabeçalho.
Ao criar a sala, escolha o idioma das perguntas e conteúdo global, brasileiro
ou misto. Todos disputam as mesmas perguntas, mesmo usando interfaces diferentes.
Detalhes: docs/INTERNACIONALIZACAO.md.

LUDRIVO ARENA
Palco animado, personagens, plataformas, cartas secretas e duetos.
Escolha uma carta nos bastidores; na arena, mova com 1–4/setas ou clique
numa plataforma. Depois use Enter ou Travar resposta para confirmar.
Os acertos da turma liberam BIS, com bônus e perdas das cartas em dobro.
Regras completas e exemplos: docs/MOSH_ARENA.md.

OPÇÃO A — COM DOCKER
1. Instale e abra o Docker Desktop (containers Linux).
2. Execute iniciar-docker.bat.
3. Abra http://localhost:8080.

OPÇÃO B — SEM DOCKER
1. Instale Java 25.
2. Execute iniciar-pc.bat.
3. Após a mensagem Started QuizMoshServer, abra http://localhost:8080.
   O arquivo releases/ludrivo.jar é gerado pelo build (veja README.md).

Escolha um apelido. Para experimentar sozinho, clique em Treine com bots.
Depois, no lobby, clique em Começar a partida.

Para convidar pela rede, abra pelo IPv4 do PC em vez de localhost.
Exemplo: http://192.168.1.20:8080 (substitua pelo IP real do seu PC).

Leia README.md para configuração e desenvolvimento, docs/OPERACAO.md para
hospedagem, docs/CONTEUDO_E_ASSETS.md para licenças e docs/VALIDACAO.md para os
testes executados e suas limitações.

Salas ativas ficam em memória e são encerradas ao reiniciar o servidor.
O placar das partidas concluídas é arquivado no banco.
